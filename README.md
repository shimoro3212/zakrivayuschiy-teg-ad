# Закрывающий тег

**«Закрывающий тег»** — учебный веб-проект, посвящённый процессу изучения веб-разработки. Сайт представляет собой интерактивный блог с карточками, в которых отражены разные этапы обучения, впечатления и достижения.

Основное внимание уделено работе с CSS-анимациями, адаптивной вёрстке и интерактивными элементами интерфейса.

## Функциональность

- Адаптивная вёрстка для разных размеров экранов.
- Поддержка светлой и тёмной цветовых тем.
- Анимированная кнопка Like в виде сердца.
- Плавные переходы и эффекты при наведении на элементы.
- Оформление изображений с использованием CSS-фильтров.
- Использование SVG-графики и декоративных элементов.

## Используемые технологии

- **HTML5** — семантическая разметка страницы.
- **CSS3** — стилизация, адаптивность и анимации.
- **JavaScript** — интерактивность кнопок.
- **SVG** — иконки и графические элементы.
- **Git и GitHub** — контроль версий и хранение проекта.

## Запуск проекта

1. Клонировать репозиторий:

   `git clone https://github.com/shimoro3212/zakrivayuschiy-teg-ad.git`

2. Перейти в папку проекта:

   `cd zakrivayuschiy-teg-ad`

3. Открыть файл `index.html` в браузере.

Также можно запустить проект через расширение **Live Server** в Visual Studio Code.

Для работы сайта не требуется установка дополнительных зависимостей.

## Структура проекта

- `index.html` — основная HTML-разметка.
- `styles/` — CSS-файлы со стилями и анимациями.
- `scripts/` — JavaScript-файлы.
- `images/` — изображения.
- `fonts/` — локальные шрифты.
- `svg/` — SVG-изображения и иконки.

## Цель проекта

Закрепить навыки адаптивной вёрстки, работы с CSS-анимациями, SVG-графикой, псевдоклассами и интерактивными элементами интерфейса.
